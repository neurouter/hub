# @neurouter/web

The Neurouter admin console and user portal: Vite 8, React 19, TanStack Router and Query,
Tailwind 4 and shadcn on Base UI. The app is always same-origin with the backend. In dev, Vite
proxies to the backend. In production, the Fastify server serves `dist/`.

## Develop

All variables live in the repo-root `.env` (see `.env.example`).

| Variable | Purpose |
|---|---|
| `NEUROUTER_DEV_API_URL` | **Required for `npm run dev:web`.** The backend origin that Vite proxies `/api`, `/mcp`, `/oauth`, `/.well-known` and `/metrics` to. The code never hardcodes hosts. |
| `NEUROUTER_WEB_DEV_PORT` | Optional Vite port. |
| `VITE_ENABLE_MSW` | `true` runs the UI with no backend, against MSW handlers generated from the shared contract plus the demo dataset in `src/mocks/`. Dev only; never part of the build. |
| `PUBLIC_URL` (backend) | Set it to the Vite origin when you use the UI through Vite, so OIDC and OAuth redirects come back to Vite. |

```bash
npm run dev            # server + web (repo root)
npm run dev:web        # web only (needs a running backend, or VITE_ENABLE_MSW=true)
```

Server-sent events (`/api/approvals/stream`) pass through the Vite proxy unbuffered.

## Test, typecheck, build

```bash
npx vitest run                 # unit tests (jsdom + Testing Library + MSW), from apps/web
npx tsc -b                     # typecheck app, node and test projects
npm run build -w @neurouter/web
npm run size -w @neurouter/web # initial-load budget (gzip) after a build
```

`bundle-budget.ts` counts the entry script, every `modulepreload` and the initial CSS from
`dist/index.html`, measured gzipped. The budget is 250 KiB for JS and 40 KiB for CSS. Lazy route
chunks (charts, audit, settings) are not counted.

## Production serving

The backend serves `dist/` when `SERVE_WEB=true`, which is the default in production. It uses
`WEB_DIST_DIR` and defaults to `../web/dist`.

- **Caching:** `/assets/*` is immutable for a year. `index.html` and `theme-init.js` are `no-cache`.
- **SPA fallback:** every other `GET` that accepts HTML gets `index.html`, so deep links reload. The
  fallback never applies to `/api`, `/mcp`, `/oauth`, `/.well-known`, `/metrics` or the health paths.
- **CSP:** `script-src 'self'` with no inline scripts and no `unsafe-eval`, plus
  `frame-ancestors 'none'`, which covers the consent page.
  - The pre-paint script `public/theme-init.js` is an external file. It also sets zod's
    `jitless` mode before the bundle loads, so zod never probes `new Function`, which the browser
    would report as a CSP violation.
  - Images are limited to the app's own origin. The backend proxies server icons, and the consent
    page renders a client logo only from a same-origin path.

## Layout

- `src/routes/`: file routes. `routeTree.gen.ts` is generated by the router plugin and committed.
- `src/features/<domain>/`: queries, components and tests per area. Examples:
  - `approvals/` holds the live queue, built on `lib/live.ts`.
  - `consent/` is the MCP OAuth consent page.
  - `connections/` handles per-user upstream OAuth.
  - `search/` is the ⌘K palette.
  - `settings/`
- `src/lib/live.ts`: `createLiveChannel` wraps EventSource and reports a status (`open`,
  `degraded`, `paused`). Consumers poll while the channel is degraded. Tests inject
  `createFakeTransport()`.
- `src/lib/server-time.ts`: the server clock offset from `/api/me.serverTime`, used for countdowns.
